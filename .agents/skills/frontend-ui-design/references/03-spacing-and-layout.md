# 03 — Spacing and Layout

Spacing is a semantic tool. Closeness communicates relationship; distance communicates separation.

## Reference spacing scale

A useful scale learned from the training references:

`4 / 8 / 16 / 24 / 32 / 48 / 64 / 80 / 120`

Typical uses:
- 4–8 px: icon-label gaps, micro-spacing, tightly coupled text
- 16 px: common internal component spacing
- 24–32 px: card padding, related block separation
- 48–64 px: section grouping
- 80–120 px: major section breaks and strong visual resets

These are references, not mandatory constants.

## Proximity rules

1. Related elements should sit closer together.
2. Unrelated groups need more separation.
3. Internal spacing should usually be smaller than external spacing.
4. Do not use identical vertical gaps everywhere; hierarchy requires multiple spacing levels.
5. Alignment edges should remain consistent across headings, forms, cards, buttons, and sections.

## Card density

Useful starting points:
- compact cards: ~8 px padding
- standard cards: ~16 px padding
- roomy / premium cards: ~24 px or more

Density should match the product. Operational dashboards need tighter layouts than luxury marketing pages.

## Mobile form rhythm reference

From the spacing training reference:
- 44×44 px back/navigation touch target
- about 56 px input/control height
- around 8 px between tightly related text
- around 16 px between a field and secondary/supporting text
- larger layout regions around 80–96 px in the demonstrated composition

## Responsive spacing

Responsive design is not simply scaling all values down. On smaller screens:
- reduce major gaps first when needed
- preserve touch targets
- maintain grouping relationships
- stack/recompose content rather than crushing it
- keep readable line lengths and padding

## Layout hierarchy

Use spacing to distinguish:
- global navigation
- page heading/context
- primary content
- secondary supporting areas
- actions
- major section transitions

## Rule
> If users can understand which elements belong together without borders, the spacing system is doing its job.
