# 09 — Mobile Commerce and Card Systems

## Mobile commerce reference dimensions
The training reference used an iPhone-sized frame around `402 × 874 px` and demonstrated a practical compact commerce layout.

Reference values:
- side margins: ~16 px
- promotional banner: ~370 × 150 px
- banner radius: ~12–16 px
- two-column card width: ~179 px
- gap between cards: ~12 px
- product image region: ~179 × 160 px
- total product card height: ~240–280 px
- section spacing: ~24 px
- card padding: ~12 px
- button height: ~48 px
- common radius: ~12–16 px

Typography reference:
- heading: ~20–24 px
- product name: ~14 px
- price: ~16 px
- body: ~14 px
- caption: ~12 px

These are starting references, not fixed rules.

## Product-card hierarchy
A strong product card usually communicates in this order:
1. product image
2. product name
3. important metadata such as rating/discount only when useful
4. current price
5. previous price if discounted
6. clear purchase action

Avoid excessive metadata that slows browsing.

## Grid principles
- Maintain stable card proportions.
- Keep gutters consistent.
- Preserve image aspect ratios.
- Use predictable alignment across rows.
- Do not allow one card’s content to create chaotic vertical rhythm.
- Adapt column count responsively instead of shrinking cards indefinitely.

## Promotional banners
Promotional content should be noticeable but not consume unnecessary vertical space. Keep the message short and the CTA clear.

## Mobile card design
Cards should not depend on heavy shadows. Use spacing, surface contrast, image framing, and restrained radius first.

## E-commerce action design
Purchase actions should have comfortable hit targets and clear hierarchy. If the entire card is clickable, still make the purchase or detail action understandable.

## Responsiveness
When width decreases:
- preserve side margins where possible
- reduce card count per row before crushing card content
- maintain readable price/product text
- keep touch targets usable

## Rule
> Commerce UI should optimize scanning: image first, decision information second, action last.
