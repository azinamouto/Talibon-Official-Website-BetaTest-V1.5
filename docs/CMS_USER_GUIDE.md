# CMS User Guide

## Overview

This guide provides instructions for municipal staff using the Content Management System (CMS) of TAL.GOV.

## Getting Started

### Accessing the CMS

1. Navigate to https://talibon.gov.ph/admin
2. Enter your email and password
3. Complete two-factor authentication if enabled
4. You will be directed to the CMS dashboard

### Dashboard Overview

The CMS dashboard provides:
- Quick statistics (total services, news items, etc.)
- Recent activity log
- Pending approvals
- System notifications

## Content Management

### Creating a Service

1. Navigate to Services > Create Service
2. Fill in service details:
   - **Service Name**: Official name of the service
   - **Department**: Select responsible department
   - **Description**: Brief overview of the service
   - **Eligibility**: Who can avail of the service
   - **Requirements**: Documents and information needed
   - **Steps**: Step-by-step process
   - **Fees**: Cost breakdown
   - **Processing Time**: Expected completion time
   - **Office Location**: Where to apply
   - **Contact Information**: How to reach the office
3. Upload related documents
4. Preview the service page
5. Submit for review or publish directly (if authorized)

### Editing a Service

1. Navigate to Services > All Services
2. Find the service you want to edit
3. Click the Edit button
4. Make necessary changes
5. Preview changes
6. Save as draft or publish

### Deleting a Service

1. Navigate to Services > All Services
2. Find the service to delete
3. Click the Delete button
4. Confirm deletion
5. Note: This action cannot be undone

### Creating News Article

1. Navigate to News > Create Article
2. Fill in article details:
   - **Title**: Headline of the article
   - **Category**: Select appropriate category
   - **Content**: Full article content
   - **Excerpt**: Brief summary for listing pages
   - **Tags**: Add relevant tags
   - **Featured Image**: Upload main image
3. Set publication date (optional)
4. Preview the article
5. Submit for review or publish

### Creating Announcement

1. Navigate to Announcements > Create Announcement
2. Fill in announcement details:
   - **Title**: Announcement headline
   - **Content**: Full announcement text
   - **Priority**: Normal, High, or Urgent
   - **Start Date**: When to display
   - **End Date**: When to stop displaying
3. Preview the announcement
4. Publish

### Managing Documents

1. Navigate to Documents > All Documents
2. Click Upload Document
3. Fill in document details:
   - **Title**: Document title
   - **Description**: Brief description
   - **Category**: Document category
   - **File**: Upload the file
   - **Public/Private**: Set visibility
4. Click Upload

## Media Management

### Uploading Images

1. Navigate to Media > Upload
2. Select images from your computer
3. Add alt text for accessibility
4. Add tags for organization
5. Click Upload

Supported formats: JPG, PNG, WebP, GIF
Maximum file size: 5MB

### Image Best Practices

- Use appropriate dimensions (max 2000px width)
- Compress images before upload
- Use descriptive alt text
- Organize with folders and tags

### Managing Image Library

- View all uploaded images
- Edit image metadata
- Delete unused images
- Filter by tags or folders

## Department Management

### Creating a Department

1. Navigate to Departments > Create Department
2. Fill in department details:
   - **Department Name**: Official name
   - **Description**: Department overview
   - **Head of Office**: Department head
   - **Location**: Office address
   - **Phone**: Contact number
   - **Email**: Email address
   - **Office Hours**: Operating hours
3. Save department

### Editing Department

1. Navigate to Departments > All Departments
2. Select department to edit
3. Update information
4. Save changes

## User Management

### Creating User Account

1. Navigate to Users > Create User
2. Fill in user details:
   - **Email**: User's email address
   - **First Name**: User's first name
   - **Last Name**: User's last name
   - **Role**: Assign user role
   - **Department**: Assign department (if applicable)
3. Send invitation email
4. User will receive setup instructions

### Managing User Roles

1. Navigate to Users > All Users
2. Select user
3. Click Edit Role
4. Select new role
5. Confirm change

### Deactivating User

1. Navigate to Users > All Users
2. Select user
3. Click Deactivate
4. Confirm deactivation
5. User will no longer be able to login

## Content Approval Workflow

### Submitting for Approval

Editors must submit content for approval before publishing:

1. Create or edit content
2. Click Submit for Approval
3. Admins will review the content
4. Admins can approve, reject, or request changes

### Reviewing Content

Admins review submitted content:

1. Navigate to Pending Approvals
2. Click on content to review
3. Review for:
   - Accuracy
   - Completeness
   - Spelling and grammar
   - Formatting
   - Compliance with guidelines
4. Approve, reject, or request changes

### Publishing Approved Content

Once approved, content can be published:
1. Navigate to Approved Content
2. Click Publish
3. Content is now live on the website

## Best Practices

### Content Creation

- **Accuracy**: Verify all information before publishing
- **Clarity**: Use clear, simple language
- **Completeness**: Include all relevant information
- **Consistency**: Follow style guidelines
- **Accessibility**: Use alt text for images, proper headings

### File Management

- **Naming**: Use descriptive file names
- **Size**: Optimize files before upload
- **Format**: Use appropriate file formats
- **Organization**: Keep files organized in folders

### Security

- **Passwords**: Use strong, unique passwords
- **Logout**: Always logout when finished
- **Public Wi-Fi**: Avoid using public Wi-Fi for CMS access
- **Phishing**: Be cautious of suspicious emails

## Troubleshooting

### Common Issues

**Cannot login**
- Check email and password
- Clear browser cache
- Try different browser
- Contact administrator if still unable

**Content not publishing**
- Check if approval is required
- Verify you have publish permissions
- Check for validation errors
- Contact administrator

**Image upload fails**
- Check file size (max 5MB)
- Verify file format is supported
- Check internet connection
- Try smaller file

**Changes not appearing**
- Clear browser cache
- Hard refresh page (Ctrl+F5)
- Check if published (not draft)
- Wait for CDN cache to clear (up to 1 hour)
